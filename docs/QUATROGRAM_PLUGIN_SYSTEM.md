# Минимальная система плагинов Quatrogram

Цель: дать кастомные функции без порта тяжёлого Python-рантайма и без выполнения произвольного кода внутри приложения.

## Формат

Плагин — ZIP-файл с расширением `.qplugin`:

```text
manifest.json
resources/
  icon.png
README.md
```

Пример `manifest.json`:

```json
{
  "id": "quick_reply",
  "name": "Быстрые ответы",
  "version": "1.0",
  "min_app_version": "13.3.1",
  "description": "Добавляет пункт меню с шаблонами ответов.",
  "author": "Quatrogram",
  "hooks": [
    {
      "type": "message_context_item",
      "title": "Вставить шаблон",
      "action": {
        "type": "copy_text",
        "value": "Спасибо! Отвечу чуть позже."
      }
    }
  ],
  "settings": []
}
```

## Поддерживаемые хуки

- `main_menu_item` — пункт в боковом меню;
- `settings_item` — пункт в настройках Quatrogram;
- `message_context_item` — пункт в контекстном меню сообщения;
- `profile_action` — действие в профиле пользователя;
- `replace_string` — безопасная замена пользовательской строки по ключу.

## Поддерживаемые действия

- `open_url` — открыть ссылку во внешнем браузере;
- `copy_text` — скопировать текст;
- `show_alert` — показать диалог;
- `send_bot_command` — отправить команду боту регистрации;
- `toggle_setting` — переключить локальную булеву настройку плагина.

Запрещены: execution произвольного кода, доступ к файловой системе вне каталога плагина, доступ к сетевым сокетам, чтение токенов/сессий.

## Хранение

- каталог плагинов: `files/quatrogram/plugins/`;
- список включённых: `files/quatrogram/plugins.json`;
- при повреждённом манифесте плагин не загружается и показывается ошибка;
- аварийный режим отключает все плагины, но сохраняет список.

## UI

`Настройки → Quatrogram → Плагины`:

- список установленных плагинов;
- включить/отключить;
- удалить;
- установить из `.qplugin` через системный выбор файла;
- показать версию, автора и описание.

## Классы

- `PluginManifest` — разбор и валидация `manifest.json`;
- `PluginInfo` — загруженный плагин + состояние;
- `PluginManager` — установка, удаление, включение, отключение, safe mode;
- `PluginAction` — безопасный запуск declarative action;
- `PluginsActivity` — экран списка плагинов.

## Что не делаем

Не переносим `base_plugin.py`, `PluginsController` и Python-движок exteraGram целиком: это требует больших нативных библиотек и тесной связки с их форком.
